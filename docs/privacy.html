Privacy Policy

Last updated: March 18, 2026

The Short Version

We don't collect or store personal data. Clawlege is a static website hosted on GitHub Pages, and all learning materials are open source. When you use OpenClaw (the AI framework), it runs locally on your computer.

What We Don't Collect

  • Personal information (names, emails, addresses)
  • Login credentials (no accounts required)
  • Learning progress or completion data
  • AI conversations or agent configurations
  • Payment information (everything is free)

What We Do Collect

Like most websites, we collect basic analytics through GitHub Pages:

  • Page views and traffic patterns
  • Referrer websites (where visitors come from)
  • General geographic regions (country/city level)
  • Device and browser types

This data is anonymized and helps us understand which content is most helpful.

OpenClaw and Local Data

When you install OpenClaw:

  • All data stays on your computer
  • Your AI conversations are stored locally
  • Your API keys remain on your device
  • No data is sent to Clawlege or any third parties

Third-Party Services

We use these services, which have their own privacy policies:

  • GitHub Pages: Hosts our website and provides basic analytics
  • GitHub: Stores our open source code and handles issue tracking

Changes to This Policy

We'll update this page if our privacy practices change. Since we're open source, you can track all changes in our GitHub repository.

Questions?

If you have privacy questions, open an issue on our GitHub repository or join the discussion on Discord.
