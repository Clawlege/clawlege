# Clawlege Launch Posts — March 14, 2026

## 1. Reddit: r/learnprogramming

**Title:** I made a free, open source course that teaches anyone to build AI agents — no coding required to start

**Body:**
Hey everyone — I built [Clawlege](https://clawlege.com), a completely free course that teaches you to build your own AI agent from scratch.

**What it is:** 9 modules that take you from "what's an AI agent?" to building, deploying, and demoing a real one. The first 4 modules require zero coding — you literally write plain English files that give your agent a personality, memory, and skills.

**What you'll build:**
- Module 1-4: An agent with personality, web search, memory that persists across conversations
- Module 5: Connect it to Discord, iMessage, Telegram — your agent texts you proactively
- Module 6: Design and build your own custom agent from scratch
- Module 7: Put it on your phone or a Raspberry Pi ($35 always-on agent)
- Module 8-9: Polish it, publish it, demo it

**Who it's for:** Genuinely everyone. I've had kids and non-technical adults go through the first few modules with no issues. Developers can skip to Module 5 for the good stuff.

It's built on [OpenClaw](https://openclaw.ai), an open source agent framework. Everything runs locally on your machine — no cloud, no accounts, no data leaving your computer.

**Links:**
- Course: https://github.com/Clawlege/clawlege
- Landing page: https://clawlege.com

100% free, MIT license, no signup. Would love feedback on the curriculum — what's missing, what's confusing, what would make it better.

## 2. Reddit: r/artificial

**Title:** Open source course: build an AI agent that remembers you, searches the web, and runs on your phone — free, no coding required

**Body:**
Built a free interactive course called [Clawlege](https://clawlege.com) that teaches anyone to build personal AI agents.

Not chatbots — actual agents that take initiative, remember context across conversations, connect to your email/calendar/messages, and can run on hardware (phone, Raspberry Pi, sensors).

9 modules, ~8 hours total. First 4 need zero coding — you write your agent's personality and rules in plain English. Later modules cover channels (Discord, iMessage, Telegram), custom skills, hardware integration, and shipping your agent for others to use.

Built on OpenClaw (open source agent framework). Runs locally, privacy-first.

GitHub: https://github.com/Clawlege/clawlege

Free forever, MIT license. Happy to answer questions about the curriculum or the framework.
